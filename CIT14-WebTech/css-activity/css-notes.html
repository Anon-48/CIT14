Part I — Lecture Notes: Introduction to CSS

What Is CSS?

CSS (Cascading Style Sheets) is a stylesheet language used to control the presentation and layout of HTML documents. HTML defines the structure and content of a webpage, while CSS determines how that content looks.

Technology Primary Purpose Example
HTML Structure and content Heading, paragraph, image
CSS Presentation and layout Color, font, spacing, alignment
JavaScript Behavior and interaction Form validation, menus, dynamic content

*Without CSS, a webpage generally displays content using the browser's default styles. CSS allows developers to create attractive, consistent, and responsive interfaces.


Ways to Apply CSS

A. Inline CSS

- CSS is placed directly inside an HTML element using the style attribute.


    Advantages:
    • Quick for testing a single style.
    • Easy to demonstrate individual CSS properties
    Disadvantages:
    • Difficult to maintain across multiple elements.
    • Mixes presentation with HTML content.
    • Not recommended as the primary styling method for larger projects.
